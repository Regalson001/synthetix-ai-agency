
# SYNTHETIX AI — AI Automation & Workflow Agency

A modern, responsive landing page for a fictional AI automation agency, built with HTML5, CSS3, and vanilla JavaScript.

SYNTHETIX AI presents intelligent automation services through a premium dark interface, animated workflow previews, interactive use-case tabs, a responsive bento-grid capabilities section, pricing tiers, and an ROI calculator.

## Project Overview

The project explores how a modern AI automation agency can communicate technical services through a polished, conversion-focused web experience.

The design combines a futuristic visual identity with practical interface patterns, including CSS-driven interactions, responsive layouts, animated SVG-style workflow connections, and interactive pricing components.

**Project type:** Front-End Web Development  
**Repository:** `synthetix-ai-agency`  
**Brand concept:** SYNTHETIX AI  
**Technology:** HTML5, CSS3, JavaScript ES6+

## Design and Engineering Highlights

### Dark design system

The project uses centralized CSS custom properties for background colors, surfaces, typography, borders, and accent colors.

This makes it easier to maintain consistent visual styling and update the design.

### CSS-only use-case tabs

Radio inputs and label selectors control the visibility of each use-case panel. This demonstrates interactive CSS without requiring JavaScript to manage tab state.

### CSS Grid bento architecture

The capabilities section uses named grid areas and varying row and column spans to create an asymmetric card composition.

Responsive breakpoints reorganize the layout for smaller screens.

### Workflow visualization

The hero workflow preview uses HTML elements, SVG connection paths, and CSS keyframe animations to represent a simulated automation pipeline.

### Interactive pricing

The pricing switch updates monthly and annual displayed amounts using JavaScript and data attributes.

### ROI calculation

The calculator uses user-selected values to estimate potential time savings. It is an illustrative calculation rather than a financial guarantee.

### Progressive enhancement

The website includes reduced-motion handling and uses Intersection Observer for scroll reveal effects when supported.

## Demo and Data Disclaimer
